THE GOLDEN RATIO CRYSTAL: A NEGATIVE RESULT IN LINEAR ATTENTION

Authors: [Anonymous]
Date: January 2026
Status: CORRECTION - Original claims were invalid due to experimental error


ABSTRACT

We attempted to replace O(N²) attention with O(N) "crystallization" using fixed
geometric decay based on the Golden Ratio (φ⁻¹ = 0.618). Initial results showed
1.4 PPL vs 1.2 PPL for attention—a seemingly minor 0.2 PPL cost for linear memory.

These results were wrong.

The original implementation used bidirectional context, allowing the model to see
future tokens when predicting. This is invalid for causal language modeling. When
corrected to be truly causal (forward-only, predict-before-update), the Crystal
achieves 245-1152 PPL vs GPT-2's 44 PPL—a 5-26x performance gap.

This paper documents the error and serves as a cautionary tale about information
leakage in sequence model evaluation.


1. THE ORIGINAL CLAIM (INVALID)

We claimed Golden Ratio Crystallization could replace attention with only 0.2 PPL cost:

h_t = φ⁻¹ * h_{t-1} + x_t

Where φ⁻¹ = 0.618 provides natural convergence (the series sums to φ exactly).

Original results (NOW KNOWN TO BE WRONG):
- Crystal: 1.4 PPL
- Attention: 1.2 PPL
- Gap: +0.2 PPL

These numbers were impossibly good. GPT-2 (117M params) achieves ~44 PPL on
WikiText-2. Our 28M param model claiming 1.4 PPL would have been a breakthrough
beyond anything published.


2. THE BUG: BIDIRECTIONAL INFORMATION LEAKAGE

The original GoldenCrystal implementation had two critical flaws:

2.1 Backward Pass Sees Future

    # BACKWARD PASS - sees ALL future tokens
    for i in range(N-1, -1, -1):
        h_bwd = t[:, i] + decay * h_bwd
        bwd.append(h_bwd)

    y = fwd + bwd - t  # Combined bidirectional output

The backward pass iterates from the end of the sequence, accumulating future
context. This is valid for encoder models (BERT) but cheating for causal LM.

2.2 Predict After Update

    for i in range(N):
        h_fwd = t[:, i] + decay * h_fwd  # Update WITH current token
        fwd.append(h_fwd)                 # Then output ← leaks current token

Position i's output includes information from position i's input. For next-token
prediction, position i should only see tokens 0 to i-1.

2.3 The Attention Baseline Also Cheated

The "Standard Attention" comparison had no causal mask:

    scores = torch.matmul(q, k.transpose(-2, -1)) * self.scale
    weights = F.softmax(scores, dim=-1)  # No mask!

Both models were doing bidirectional sequence modeling, not causal LM.


3. CORRECTED RESULTS

3.1 Truly Causal Implementation

    def forward(self, token_ids):
        h = torch.zeros(batch_size, self.d_model, device=x.device)
        logits_list = []

        for i in range(seq_len):
            # STEP 1: PREDICT from previous state (causal)
            logits = self.head(h)
            logits_list.append(logits)

            # STEP 2: UPDATE state for next prediction
            x_relocated = self.relocator(x[:, i])
            h = (self.phi_inv * h) + ((1 - self.phi_inv) * x_relocated)

        return torch.stack(logits_list, dim=1)

Key changes:
- Forward-only (no backward pass)
- Predict BEFORE update (no current token leakage)

3.2 Honest Performance Numbers

Model                              Val PPL     Params      vs GPT-2
-----------------------------------------------------------------
GPT-2 (pretrained reference)       44          117M        1.0x
4-layer Forward-Only Crystal       245         28M         5.6x worse
Single-layer CausalGoldenEngram    1,152       26M         26x worse
Bidirectional Crystal (INVALID)    1.4         28M         (cheating)

The Crystal architecture is 5-26x worse than attention for causal LM, not 0.2 PPL
worse as originally claimed.


4. WHY THE CRYSTAL FAILS FOR CAUSAL LM

4.1 No Content-Dependent Routing

Attention computes: which past tokens matter for this prediction?
Crystal computes: weighted sum with fixed geometric decay

For causal LM, the model needs to selectively retrieve relevant past context.
The Crystal's fixed decay cannot learn "the word 3 positions ago is important
for this prediction but the word 2 positions ago is not."

4.2 The Backward Pass Was Carrying Everything

When we removed the backward pass, performance collapsed from 1.4 PPL to 245+ PPL.
The "Golden Ratio decay" was not learning language—the bidirectional cheating was.

4.3 Single-Direction Decay Is Too Lossy

With φ⁻¹ = 0.618:
- Distance 5:  0.618^5 = 0.09 (9% signal remaining)
- Distance 10: 0.618^10 = 0.008 (0.8% signal remaining)

By 10 tokens ago, the Crystal has lost 99.2% of the information. Language modeling
requires remembering specific tokens from much further back.


5. WHAT MIGHT STILL WORK

The Golden Crystal architecture may be valid for:

5.1 Bidirectional Tasks (Encoder Models)
- Masked language modeling (BERT-style)
- Sequence classification
- Token classification (NER, POS tagging)

For these tasks, seeing the full context is allowed, not cheating.

5.2 Very Short Contexts
Where decay doesn't significantly impact information retention.

5.3 Tasks Requiring "Contextual Essence" Not Retrieval
Where knowing the general topic matters more than specific tokens.


6. LESSONS LEARNED

6.1 Always Verify Against Known Baselines
GPT-2's ~44 PPL on WikiText-2 is well-established. Any model claiming 1.4 PPL
should have triggered immediate skepticism.

6.2 Causal LM Requires Causal Architecture
- Forward-only processing
- Predict before update
- No access to future tokens

6.3 Bidirectional ≠ Better for LM
Bidirectional context gives lower perplexity but invalid evaluation. The model
is "predicting" tokens it has already seen.

6.4 Small Gaps Hide Large Bugs
The 0.2 PPL gap (1.4 vs 1.2) between Crystal and Attention was suspiciously
small. Both models were cheating equally, masking the true performance difference.


7. CONCLUSION

The Golden Ratio Crystal does not replace attention for causal language modeling.

Original claim: 0.2 PPL cost for O(N) memory
Actual result: 5-26x worse performance

The architecture may have applications in bidirectional/encoder settings, but for
autoregressive generation (GPT-style), attention remains necessary.

This paper serves as a correction and cautionary example. Extraordinary claims
require extraordinary verification. When a 28M parameter model appears to beat
GPT-2 by 30x, the likely explanation is a bug, not a breakthrough.


APPENDIX A: THE MATHEMATICS OF PHI (Still Valid)

The Golden Ratio φ = 1.618... satisfies: φ² = φ + 1

This means: φ⁻¹ = φ - 1 = 0.618...

The geometric series: Σ φ⁻ⁱ = φ (converges exactly)

This mathematical elegance is real. The architecture just doesn't work for causal LM.
