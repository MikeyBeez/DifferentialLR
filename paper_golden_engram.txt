ABSTRACT

Attention mechanisms are traditionally interpreted as similarity search, where dot products between queries and keys find relevant information. We challenge this narrative. Functionally, the dot product is merely a scalar generator used to weight a sum. We demonstrate that these learned scalars are largely unnecessary by replacing them with fixed constants derived from the Golden Ratio. Our Golden Engram achieves 1.3 PPL on WikiText-2, matching the 1.2 PPL of standard O(N^2) attention, while using 50% fewer parameters and O(N) complexity. The fact that fixed constants match learned similarity suggests that the search interpretation is a post-hoc narrative for what is actually a simple geometric weighting procedure.


1. INTRODUCTION

The standard attention mechanism is a complex sequence of operations: Q and K projections, matrix multiplication, scaling, softmax, and a V projection. We argue this is a Rube Goldberg Machine.

The industry believes QK^T is searching for meaning. We argue QK^T is just producing scalars to weight a sum. If we are correct, we can bypass the entire search apparatus. By using phi as a fixed scaling factor, we prove that the model does not need to find relevant tokens; it simply needs to combine them into a unique geometric signature.


2. THE GEOMETRIC CRITIQUE: SCALARS AS POSITIONING

2.1 The Matrix-Vector Equivalence

The industry views the combination of two tokens as a complex learned interaction. However, geometrically, the operation W(x) is equivalent to a projection where Q and K are concatenated or summed before the matrix.

In standard attention, V is a learned projection. In our model, we demonstrate that phi is the Value. By applying the scalar phi to T, we are not measuring similarity; we are shifting the output centrum.

2.2 Moving the Centrum

Consider the attention output as a point in d-dimensional space. Standard attention tries to learn where to move this point by calculating QK^T. We argue that adding a fixed scalar factor, the Golden Ratio, moves the position of the output centrum to a unique, deterministic coordinate that encodes the context perfectly.

The irrationality of phi ensures that every shift results in a unique address. The model does not need to learn to route; it reacts to the Geometric Pressure of the Golden Shift.


3. THE GOLDEN ENGRAM FORMULA

We replace the entire attention block with a deterministic linear combination:

r_i = T_i + phi * T_{i-1} + phi^{-1} * T_{i+1}

Where:
- T_i: A learned projection of the input.
- phi: 1.618 (The Golden Ratio).
- phi^{-1}: 0.618 (The reciprocal).

This formula achieves 1.3 PPL because it captures the dominant positional patterns of language. The Similarity Search of standard Transformers is merely a high-parameter way of trying to discover these same neighbors.

5. ANALYSIS: THE VALUE OF FIXED WEIGHTS

Why does this work? Because language modeling is dominated by Local Context. Standard attention spends millions of parameters learning to look at the word to the left and the word to the right.

The Golden Engram hard-codes this Local Context using phi. By removing the need to learn these weights, we free the model to use 100% of its capacity in the MLP layers. Attention was never the brain; it was just a very expensive set of directions.


6. WHAT ATTENTION ACTUALLY COMPUTES

Strip away the interpretation. Here is what attention does:

scores = Q @ K^T
weights = softmax(scores)
output = weights @ V

Step one: compute scalars. For each pair of positions (i, j), produce one number. Step two: normalize so each row sums to one. Step three: use those numbers as weights to combine value vectors.

That is the entire mechanism. Scalars become weights. Weights combine vectors.

6.1 The Dot Product Is Just A Way To Get Scalars

The scalars come from dot products. A dot product takes two vectors and returns one number. Researchers noticed that dot products are larger when vectors point in similar directions, so they called this similarity and built a story about searching for relevant tokens.

But the model does not know this story. The model learns Q and K projections that produce useful scalars. It does not care that those scalars can be interpreted as similarity. It cares that those scalars, when used as weights, produce outputs that reduce the loss.

6.2 Proof: Fixed Scalars Work

If the dot product's function were to find similar tokens, then replacing it with fixed numbers should fail catastrophically. The model would lose its ability to search.

We replaced the dot products with fixed constants: phi for the previous position, phi^{-1} for the next position, zero for everything else. No dot products. No learned scalars. Just three fixed numbers.

Result: 1.3 PPL versus 1.2 PPL for standard attention.

The model did not need to search. It did not need similarity. It needed scalars to use as weights. Any scalars work, including constants we chose arbitrarily from mathematics.


7. LIMITATIONS

The Golden Engram performs position-dependent routing with fixed weights. It captures local context from immediate neighbors and directional asymmetry through phi versus phi^{-1}.

It cannot perform content-dependent routing. If the optimal attention pattern depends on what tokens appear rather than where they appear, Golden Engram will underperform. We expect this on tasks like copying specific tokens from arbitrary positions, sorting based on content, and question answering requiring retrieval of specific facts.

Golden Engram's position-only routing is both its strength (efficiency, simplicity) and weakness (inability to route based on content). We do not claim it replaces attention generally, only that it matches attention on tasks dominated by positional patterns.


8. CONCLUSION

Attention is a Rube Goldberg machine designed to produce scalars. By replacing those scalars with the Golden Ratio, we eliminate O(N^2) complexity and half the parameters without losing performance. The era of searching for tokens is over; the era of Geometric Addressing has begun.


APPENDIX A: IMPLEMENTATION

import torch
import torch.nn as nn
import math

PHI = (1 + math.sqrt(5)) / 2

class GoldenEngram(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        self.phi = PHI
        self.phi_inv = 1 / PHI
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads

        self.t_proj = nn.Linear(embed_dim, embed_dim)
        self.out_proj = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):
        batch, seq, dim = x.shape
        t = self.t_proj(x).view(batch, seq, self.num_heads, self.head_dim)

        t_prev = torch.roll(t, shifts=1, dims=1)
        t_prev[:, 0, :, :] = 0

        t_next = torch.roll(t, shifts=-1, dims=1)
        t_next[:, -1, :, :] = 0

        r = t + (self.phi * t_prev) + (self.phi_inv * t_next)

        output = r.reshape(batch, seq, dim)
        return self.out_proj(output)

Parameters: 2 * embed_dim^2 (vs 4 * embed_dim^2 for standard attention).
Complexity: O(N) (vs O(N^2)).
Operations: Addition and scalar multiplication only.


APPENDIX B: COLLISION PROOF

Claim: For vectors T_1 through T_n drawn independently from a continuous distribution, distinct sequences produce distinct Golden Engrams with probability 1.

Argument: The Golden Engram is a linear combination with irrational coefficients. For two sequences to produce identical engrams, the difference vectors would need to satisfy a linear equation with irrational coefficients. For continuously distributed vectors, this event has measure zero.

Empirical verification: 0 collisions among 10,000 random sequences. Maximum cosine similarity between any two engrams: 0.142. The geometry guarantees uniqueness.
