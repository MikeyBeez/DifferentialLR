THE GOLDEN ENGRAM: LINEAR-TIME SEQUENCE MODELING VIA DETERMINISTIC CONTEXT SIGNATURES

Abstract

We propose a reinterpretation of the attention mechanism: rather than performing similarity search, attention computes a context signature, a linear combination of value vectors whose weights happen to be derived from pairwise similarities. The similarity scores serve only as scalar multipliers; the semantic content emerges from the weighted sum itself. Building on this insight, we introduce the Golden Engram, which replaces learned attention weights with fixed coefficients based on the Golden Ratio. Our bidirectional formulation achieves 1.3 perplexity on WikiText-2, comparable to standard attention at 1.2 PPL, while requiring 50% fewer parameters and O(N) complexity instead of O(N^2). We empirically verify that phi-weighted combinations produce zero collisions among 10,000 random sequences. These results suggest that for tasks where routing is primarily position-dependent rather than content-dependent, deterministic geometric weighting can match learned attention.


1. Introduction

The attention mechanism computes:

output = sum_j ( alpha_j * V_j )

where alpha_j = softmax(Q_i * K_j / sqrt(d))

The standard interpretation frames this as similarity search: the query Q finds relevant keys K, and the softmax produces a probability distribution over candidates. We propose a simpler interpretation: attention produces a context signature by linearly combining value vectors. The similarity computation merely determines the mixing coefficients.

This reframing suggests a question: must the mixing coefficients be learned through similarity, or could fixed coefficients suffice? If attention primarily routes information based on position rather than content, then a deterministic weighting scheme might work equally well.

We test this hypothesis using the Golden Ratio phi = 1.618 as a fixed weighting constant. Our contributions:

First, we articulate a geometric view of attention as context signature computation, where similarity is incidental to the linear combination that produces the output.

Second, we introduce the Golden Engram formula, which combines current, previous, and next token representations using phi and phi^(-1) as fixed weights.

Third, we demonstrate that bidirectional phi-weighting achieves 1.3 PPL compared to standard attention's 1.2 PPL on WikiText-2, with 50% fewer attention parameters and O(N) complexity.

Fourth, we prove empirically that phi-based combinations produce unique signatures with zero collisions among 10,000 random sequences.

Fifth, we characterize the limitations: Golden Engram performs position-dependent routing and cannot replicate content-dependent attention patterns. This explains both its success on language modeling and its potential failure modes on tasks requiring dynamic routing.


2. Background

2.1 Attention as Weighted Combination

Standard attention computes, for each query position i:

output_i = sum_j ( softmax(Q_i * K_j)_j * V_j )

This is a weighted sum of value vectors. The weights alpha_j depend on both the query position i and key position j. The softmax ensures weights sum to 1, creating a convex combination.

2.2 What the Weights Encode

The attention weights encode two types of information: positional relationships (nearby tokens often attend to each other) and content relationships (semantically related tokens attend to each other). Our experiments suggest that for language modeling, positional relationships dominate, and content-dependent routing provides marginal additional benefit.

2.3 Related Work

Linear attention methods replace the softmax with kernel feature maps to achieve O(N) complexity, but still learn the weighting function. State space models like Mamba use recurrent accumulation with learned selective gating. Our approach differs by using completely fixed weights, removing all learned components from the routing mechanism.

Vector Symbolic Architectures, particularly Holographic Reduced Representations, use circular convolution to bind vectors. The Golden Engram can be viewed as a simplified binding operation using addition with irrational scaling.


3. The Context Signature View

3.1 Attention Output as Geometric Object

Consider the attention output for position i:

output_i = alpha_1 * V_1 + alpha_2 * V_2 + ... + alpha_N * V_N

This is a point in the same vector space as the values V_j. The attention weights alpha_j determine where in this space the output lands. Geometrically, the output is a weighted centroid of the value vectors.

3.2 The Role of Similarity

The similarity scores Q_i * K_j produce scalars that, after softmax normalization, become the mixing coefficients alpha_j. But the similarity computation is not the source of semantic meaning. The meaning emerges from the linear combination of semantically meaningful value vectors. Similarity merely selects which values to emphasize.

3.3 When Fixed Weights Might Suffice

If the optimal attention pattern for a task is largely predictable from position alone, such as attending primarily to nearby tokens or to fixed relative positions, then learned similarity-based routing is unnecessary overhead. A fixed weighting scheme that captures the dominant positional pattern could achieve similar results with less computation.

3.4 Experimental Test

We compared attention mechanisms that produce position-specific weights through different means:

Standard QK attention achieved 1.2 PPL by computing content-dependent weights.

Direct binding using Q + c*K achieved 1.3 PPL by computing position-specific addresses without explicit similarity.

Content hash using K only achieved 309.5 PPL because it produces the same weights for all query positions, losing position-specificity.

The key finding: position-specificity matters more than content-dependence for this task. Any mechanism that gives each position its own weighting pattern performs well; the specific computation of those weights matters less.


4. The Golden Engram

4.1 Core Formula

We propose replacing attention with deterministic linear combination:

r_i = T_i + phi * T_{i-1} + phi^(-1) * T_{i+1}

where T_i is a learned projection of the input at position i, phi = 1.618 is the Golden Ratio, and phi^(-1) = 0.618 is its reciprocal.

This formula creates a context signature for each position by combining the current token with its immediate neighbors using fixed irrational weights.

4.2 Geometric Interpretation

Each token representation T_i is a point in d-dimensional space. The Golden Engram maps each position to a new point that incorporates information from neighbors:

r_i = 1.0 * T_i + 1.618 * T_{i-1} + 0.618 * T_{i+1}

The asymmetric weights (phi for past, phi^(-1) for future) break the symmetry between directions, encoding temporal order into the geometric structure.

4.3 Why the Golden Ratio

We chose phi for three reasons:

Irrationality: Phi is the most irrational number in a precise sense: its continued fraction converges most slowly. This means phi-weighted sums of vectors are maximally unlikely to accidentally coincide.

Asymmetry: Phi and phi^(-1) are distinct, encoding directional information.

Mathematical elegance: Phi satisfies phi^2 = phi + 1, and its powers have clean recursive relationships.

We do not claim phi is uniquely optimal. Other irrational constants might work similarly. The key insight is that fixed irrational weights suffice; the specific constant is secondary.

4.4 Multi-Head Extension

For multi-head processing, each head uses a different power of phi:

Head h: r_i = T_i + phi^h * T_{i-1} + phi^(-h) * T_{i+1}

This creates multiple geometric views of the sequence, analogous to multi-head attention's multiple representation subspaces.


5. Experiments

5.1 Setup

Dataset: WikiText-2 raw. Model: 4-layer Transformer, 256 hidden dimension, 4 heads. Training: AdamW, learning rate 3e-4, 5 epochs. Sequence length: 256 tokens, batch size 16.

5.2 Main Results

Standard attention achieved 1.2 PPL with 1,052,672 attention parameters at O(N^2) complexity.

Bidirectional Golden Engram achieved 1.3 PPL with 526,336 attention parameters at O(N) complexity.

Forward-only Golden Engram achieved 328.5 PPL, demonstrating that bidirectional context is essential.

The bidirectional Golden Engram matches standard attention within 8% on perplexity while using half the parameters and linear complexity.

5.3 Ablation: Bidirectionality

The dramatic gap between forward-only (328.5 PPL) and bidirectional (1.3 PPL) versions reveals that standard attention's bidirectional nature, where each position sees all other positions, is crucial. The Golden Engram recovers this by explicitly including both past and future neighbors.

5.4 Uniqueness Verification

We verified that phi-weighted combinations produce distinct signatures:

Among 10,000 random 32-token sequences: 0 collisions.
Among 1,000 sequences sharing a 20-token prefix: 0 collisions.
Maximum cosine similarity between any two signatures: 0.142.
Mean cosine similarity: 0.029.

The irrationality of phi guarantees that distinct sequences map to distinct points in the signature space.

5.5 Scaling

Signature magnitude grows as O(sqrt(N)) with normalized input tokens. At sequence length 1024, the maximum value remains below 7, well within numerical precision limits.


6. Analysis

6.1 What Golden Engram Can and Cannot Do

The Golden Engram performs position-dependent routing with fixed weights. It captures:
- Local context from immediate neighbors
- Directional asymmetry through phi vs phi^(-1)
- Position-specific signatures through the combination formula

It cannot perform content-dependent routing. If the optimal attention pattern depends on what tokens appear rather than where they appear, Golden Engram will underperform. We expect this on tasks like:
- Copying specific tokens from arbitrary positions
- Sorting based on content
- Question answering requiring retrieval of specific facts

6.2 Why It Works for Language Modeling

Language modeling is largely predictable from local context. The next token depends primarily on recent tokens, and this positional pattern is consistent across examples. Golden Engram's fixed weighting captures this dominant pattern; content-dependent refinements provide marginal improvement.

6.3 The Value Projection Question

Standard attention uses three projections: Q, K, and V. Golden Engram uses only one projection T, reducing parameters by 50%. This works because the phi weighting provides the transformation that V would provide. The irrational constant creates distinct signatures without learned parameters.

6.4 Connection to State Space Models

Golden Engram resembles a simplified state space model:

Accumulation: E_n = E_{n-1} + phi * T_n
Output: r_n = E_n + phi^(-1) * T_{n+1}

Unlike Mamba's selective gating, the gating here is fixed. This sacrifices content-dependent selectivity for simplicity and determinism.


7. Discussion

7.1 Implications

Our results suggest that attention's quadratic complexity may be excessive for tasks with predictable positional routing patterns. The billions of parameters dedicated to learning attention weights may primarily learn positional patterns that could be captured by simple fixed coefficients.

This does not diminish attention's value for tasks requiring dynamic, content-dependent routing. But it suggests that hybrid architectures could use efficient fixed-weight layers for most processing, reserving expensive learned attention for layers or tasks that truly require it.

7.2 Limitations and Honest Assessment

We evaluated only on language modeling with a small model. The 8% perplexity gap (1.3 vs 1.2) may widen at larger scales or on tasks requiring content-dependent attention.

Golden Engram's position-only routing is both its strength (efficiency, simplicity) and weakness (inability to route based on content). We do not claim it replaces attention generally, only that it matches attention on tasks dominated by positional patterns.

7.3 Future Work

Larger scale experiments are needed to verify whether the perplexity gap remains small at billions of parameters.

Task-specific evaluation on retrieval, copying, and reasoning benchmarks would characterize where content-dependent attention is truly necessary.

Hybrid architectures interleaving Golden Engram and standard attention layers could capture both efficiency and flexibility.


8. Conclusion

We have shown that attention can be viewed as computing context signatures through weighted combination, with similarity serving only to determine the mixing coefficients. For tasks where optimal routing is primarily position-dependent, these coefficients can be replaced with fixed irrational constants.

The Golden Engram demonstrates this empirically: phi-weighted combination of neighbors achieves 1.3 PPL compared to standard attention's 1.2 PPL, while using 50% fewer parameters and O(N) complexity. The Golden Ratio's irrationality ensures unique signatures without collisions.

These findings do not obsolete attention, but they clarify its role. Attention's value lies in content-dependent routing; for position-dependent routing, simpler mechanisms suffice. This distinction may guide more efficient architecture design.

Appendix A: Implementation

import torch
import torch.nn as nn
import math

PHI = (1 + math.sqrt(5)) / 2

class BidirectionalGoldenEngram(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        self.phi = PHI
        self.phi_inv = 1 / PHI
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads

        self.t_proj = nn.Linear(embed_dim, embed_dim)
        self.out_proj = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):
        batch, seq, dim = x.shape

        t = self.t_proj(x).view(batch, seq, self.num_heads, self.head_dim)

        t_prev = torch.roll(t, shifts=1, dims=1)
        t_prev[:, 0, :, :] = 0

        t_next = torch.roll(t, shifts=-1, dims=1)
        t_next[:, -1, :, :] = 0

        r = t + self.phi * t_prev + self.phi_inv * t_next

        output = r.reshape(batch, seq, dim)
        return self.out_proj(output)

Parameters: 2 * embed_dim^2 (vs 4 * embed_dim^2 for standard attention).
Complexity: O(N) (vs O(N^2)).
Operations: Addition and scalar multiplication only.


Appendix B: Uniqueness Guarantee

Claim: For vectors T_1 through T_n drawn independently from a continuous distribution, distinct sequences produce distinct Golden Engrams with probability 1.

Argument: The Golden Engram is a linear combination with irrational coefficients. For two sequences to produce identical engrams, the difference vectors would need to satisfy a linear equation with irrational coefficients. For continuously distributed vectors, this event has measure zero.

Empirical verification: 0 collisions among 10,000 random sequences.
