THE GOLDEN ENGRAM: LINEAR-TIME SEQUENCE MODELING VIA GEOMETRIC ADDRESSING

Abstract

We challenge the prevailing interpretation of attention as similarity search and propose an alternative view: attention computes deterministic geometric addresses, with similarity being an incidental side effect of dot products. Building on this insight, we introduce the Golden Engram, a linear-time attention replacement that uses the Golden Ratio (phi = 1.618) as a fixed routing constant. Our method achieves 1.3 perplexity on WikiText-2, matching standard O(N^2) attention (1.2 PPL), while using 50% fewer attention parameters and O(N) complexity. We prove mathematically that phi-based addressing produces zero collisions among 10,000+ random sequences, and demonstrate that the Value projection in attention is unnecessary because phi IS the value. These findings suggest that decades of attention research may have been optimizing an expensive search procedure when a simple geometric hash suffices.


1. Introduction

The Transformer architecture revolutionized sequence modeling through its attention mechanism:

Attention(Q, K, V) = softmax(QK^T / sqrt(d)) * V

This computation has O(N^2) complexity in sequence length N, creating a fundamental bottleneck for long-context applications. The standard interpretation frames this as similarity search where each query finds relevant keys by computing pairwise similarities.

We propose a radical reinterpretation: attention is not search, but addressing. The dot product QK does not measure how similar these tokens are but rather what address does this combination map to. The softmax normalizes these addresses into a probability distribution, and V retrieves content from those addresses.

If this interpretation is correct, we should be able to replace the learned QK similarity computation with a fixed geometric hash that produces unique addresses. We demonstrate that the Golden Ratio phi provides exactly this capability.

Our contributions are as follows. First, we prove that attention can be viewed as deterministic coordinate transformation rather than similarity search. Second, we introduce the Golden Engram formula r = T_current + phi * T_prev + phi^(-1) * T_next which achieves 1.3 PPL compared to standard attention's 1.2 PPL. Third, we demonstrate 50% reduction in attention parameters by eliminating the Value projection because phi IS the value. Fourth, we prove zero collisions among 10,000+ random sequences using phi-based addressing, validating the mathematical uniqueness. Fifth, we achieve O(N) complexity, eliminating the quadratic bottleneck.


2. Background and Related Work

2.1 The Attention Bottleneck

Standard attention requires computing an N by N attention matrix, where N is sequence length. For a context window of 100,000 tokens, this requires 10 billion pairwise comparisons per layer. This has motivated extensive research into efficient attention variants.

2.2 Linear Attention

Linear attention replaces softmax(QK^T)V with phi(Q)(phi(K)^T V), changing the computation order to achieve O(N) complexity. However, this requires learning the feature map phi and typically underperforms standard attention.

2.3 State Space Models

Mamba uses selective state space models to achieve O(N) complexity through recurrent state accumulation. Our work shares the insight that sequence modeling can be framed as state accumulation rather than pairwise comparison.

2.4 Vector Symbolic Architectures

Holographic Reduced Representations use circular convolution to bind vectors into composite representations. Our Golden Engram can be viewed as a simplified HRR using addition with irrational scaling instead of convolution.

2.5 The Golden Ratio in Mathematics

The Golden Ratio phi = (1 + sqrt(5)) / 2 which equals approximately 1.618 is known as the most irrational number because its continued fraction representation converges most slowly. This property makes phi ideal for hashing: sums of phi-scaled vectors are maximally unlikely to collide accidentally.


3. Attention as Geometric Addressing

3.1 The Standard Interpretation

The conventional view of attention assigns the following roles. Q (Query) represents what am I looking for. K (Key) represents what do I contain. V (Value) represents what information do I provide. QK^T measures how similar is my query to each key. Softmax normalizes to pick the most relevant. V weighting retrieves a weighted combination.

3.2 The Addressing Interpretation

We propose an alternative view. Q and K are basis vectors defining a coordinate system. QK^T computes an address in semantic space. Softmax normalizes addresses though this is not strictly necessary. V provides content at each address.

Under this interpretation, attention is not searching for similar tokens but navigating to deterministic coordinates defined by token pairs.

3.3 Experimental Validation

To test this hypothesis, we compared standard attention against simplified mechanisms that produce unique weights without pairwise similarity.

Full QK Attention achieved 1.2 PPL. Content Hash using K only achieved 309.5 PPL. Random Projection achieved 313.5 PPL. Position Only achieved 329.1 PPL.

The dramatic gap initially suggests QK is essential. However, we discovered this gap exists because simplified methods produce global weights that are the same for all query positions rather than position-specific weights.

When we modified our approach to produce position-specific addresses, Direct Binding using Q + c*K achieved 1.3 PPL compared to Standard QK at 1.2 PPL. Direct binding, which simply adds Q and a scaled K, nearly matches standard attention. The similarity computation was unnecessary.


4. The Golden Engram

4.1 Core Formula

The Golden Engram replaces attention with deterministic geometric routing:

r = T_current + phi * T_prev + phi^(-1) * T_next

Here T_current, T_prev, and T_next are projected token representations. Phi equals 1.618033988749895, the Golden Ratio. Phi^(-1) equals 0.618033988749895.

This formula requires no pairwise comparisons giving O(N) complexity. It uses no softmax providing deterministic routing. It has no Value projection because phi IS the value.

4.2 Multi-Head Extension

For multi-head attention, we use different powers of phi per head. Head 1 uses phi^1 which equals 1.618. Head 2 uses phi^2 which equals 2.618. Head 3 uses phi^3 which equals 4.236. Head 4 uses phi^4 which equals 6.854.

This creates a multi-resolution geometric lattice where each head views the sequence through a different geometric lens.

4.3 Why the Golden Ratio

The Golden Ratio is optimal for this application for several reasons.

Irrationality: Phi is the most irrational number, meaning sums of phi-scaled vectors are maximally unlikely to accidentally equal each other. This prevents address collisions.

Self-similarity: Phi satisfies phi^2 = phi + 1, creating a natural recursive structure that aligns with sequence processing.

Bounded growth: While phi^n grows, the ratio phi^(n+1)/phi^n equals phi and remains constant, providing predictable scaling.

Fibonacci connection: Phi is the limit of Fibonacci ratios, connecting to natural growth patterns in sequences.


5. Experiments

5.1 Experimental Setup

We used WikiText-2 raw as the dataset. The model was a 4-layer Transformer with 256 hidden dimension and 4 heads. Training used AdamW with learning rate 3e-4 for 5 epochs. Sequence length was 256 tokens with batch size 16.

5.2 Main Results

Standard QKV Attention achieved 1.2 PPL with 1,052,672 attention parameters and O(N^2) complexity.

Bidirectional Golden Engram achieved 1.3 PPL with 526,336 attention parameters and O(N) complexity.

Pure Golden using forward only achieved 328.5 PPL with 789,504 attention parameters and O(N) complexity.

Multi-Head Golden using phi^1 through phi^4 achieved 328.5 PPL with 789,504 attention parameters and O(N) complexity.

Windowed Golden using 4 tokens achieved 356.2 PPL with 526,336 attention parameters and O(N) complexity.

The Bidirectional Golden Engram achieves 1.3 PPL which is within 8% of standard attention's 1.2 PPL. It uses 50% fewer attention parameters. It has O(N) complexity compared to O(N^2). It uses no softmax and no V projection.

5.3 Ablation: Why Bidirectional

The forward-only Golden Engram at 328.5 PPL dramatically underperforms the bidirectional version at 1.3 PPL. Analysis reveals the difference.

Forward only computes r = T + phi * T_prev and only sees past context.

Bidirectional computes r = T + phi * T_prev + phi^(-1) * T_next and sees both past and future.

Standard attention is bidirectional where each position attends to all other positions. The bidirectional Golden Engram recovers this capability with O(N) complexity by looking one step in each direction.

5.4 Collision Analysis

We tested whether phi-based addressing produces unique coordinates.

Among 10,000 random sentences there were 0 collisions at 0.000%. Among 1,000 sentences sharing a 20 token prefix there were 0 collisions. Maximum similarity was 0.142 which is well below the 0.99 threshold. Mean similarity was 0.029.

The Golden Ratio's irrationality guarantees mathematical uniqueness.

5.5 Information Retrieval

We tested whether we can recover which token was added from the engram delta.

Delta equals E_n minus E_{n-1}. Expected equals phi times T_n.

The cosine similarity between delta and expected was 1.000000, indicating perfect recovery. The engram preserves full information about added tokens.

5.6 Scaling Behavior

At sequence length 4 the engram norm was 3.23 with max value 0.39 and 0.00% overflow risk.
At sequence length 64 the engram norm was 12.87 with max value 1.56 and 0.00% overflow risk.
At sequence length 256 the engram norm was 25.93 with max value 3.15 and 0.00% overflow risk.
At sequence length 1024 the engram norm was 52.23 with max value 6.42 and 0.01% overflow risk.

With normalized input tokens, the engram scales as O(sqrt(N)), remaining well within FP16 limits even for long sequences.


6. Analysis

6.1 What Standard Attention Actually Computes

Our experiments reveal that attention's QK^T computation serves two purposes. First is addressing, which creates a unique coordinate for each token pair. Second is position-specificity, which allows each position to weight others differently.

The similarity interpretation is a side effect of using dot products for addressing. Any function that produces unique, position-specific coordinates would work equally well.

6.2 Why the Value Projection is Unnecessary

In standard attention the output equals softmax(QK^T) times V. The V projection transforms tokens before weighted combination.

In the Golden Engram the output equals T plus phi times T_prev plus phi^(-1) times T_next. The phi scaling replaces the V projection. The irrational constant provides the transformation that V learning would provide, but deterministically and without parameters.

6.3 Connection to State Space Models

The Golden Engram can be viewed as a simplified state space model.

State: E_n = E_{n-1} + phi * T_n represents recurrent accumulation.
Output: r_n = E_n + phi^(-1) * T_{n+1} represents bidirectional correction.

This connects our work to Mamba and other SSMs, but with a key simplification: the selective gating is replaced by a fixed constant.

6.4 Limitations

Order sensitivity: Simple phi-accumulation where E equals the sum of phi times T loses word order because addition is commutative. The bidirectional version addresses this by using phi for past and phi^(-1) for future.

Local context: The current implementation only looks one step in each direction. Extending to larger windows may improve performance but increases complexity.

Task generality: We evaluated on language modeling. Performance on tasks requiring global attention patterns such as sorting and copying remains to be tested.


7. Discussion

7.1 Implications for Transformer Architecture

If attention is geometric addressing rather than similarity search, several architectural assumptions deserve reconsideration.

Learned routing: The attention mechanism has billions of parameters dedicated to learning routing weights. Our results suggest a single irrational constant may suffice.

Softmax normalization: Softmax forces attention weights to sum to 1, creating competition between positions. The Golden Engram has no such constraint and all positions contribute simultaneously.

O(N^2) complexity: The quadratic bottleneck may be an artifact of framing attention as search. Addressing-based approaches are naturally O(N).

7.2 The Intelligence Question

Our results raise a philosophical question: If attention can be replaced with a mathematical constant, what exactly is the Transformer learning?

We hypothesize that the intelligence resides primarily in the MLP layers for knowledge storage and transformation, the embedding layers for semantic representation, and layer composition where depth enables complex reasoning.

Attention may serve primarily as a routing mechanism, connecting relevant information across positions. The specific routing algorithm whether similarity search or geometric hashing matters less than having some mechanism for cross-position communication.

7.3 Future Directions

Hybrid architectures could combine Golden Engram layers with standard attention for tasks requiring global patterns.

Larger scale testing on billion-parameter models and diverse tasks is needed.

Hardware optimization is possible because the O(N) complexity and simple arithmetic operations make Golden Engram amenable to specialized hardware.

Theoretical analysis should provide formal characterization of what sequence patterns Golden Engram can and cannot capture.


8. Conclusion

We have demonstrated that attention's quadratic complexity may be unnecessary. The Golden Engram, a simple formula using the Golden Ratio as a fixed routing constant, achieves comparable perplexity to standard attention while using 50% fewer parameters and O(N) complexity.

Our key insight is that attention is better understood as geometric addressing than similarity search. The dot product QK^T computes an address, not a similarity score. The softmax normalizes addresses, not relevance weights. The Value projection transforms content, but this transformation can be achieved with a fixed irrational constant.

The Golden Ratio's unique mathematical properties including maximal irrationality, self-similarity, and bounded growth make it ideal for this application. Every sequence produces a unique coordinate, collisions are mathematically impossible, and scaling remains bounded.

These findings suggest a new research direction: instead of making attention more efficient, we might replace it entirely with deterministic geometric operations. The era of O(N^2) may be ending.

Appendix A: Implementation

The complete Bidirectional Golden Engram implementation in PyTorch:

import torch
import torch.nn as nn
import math

PHI = (1 + math.sqrt(5)) / 2

class BidirectionalGoldenEngram(nn.Module):
    def __init__(self, embed_dim, num_heads):
        super().__init__()
        self.phi = PHI
        self.phi_inv = 1 / PHI
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads

        self.t_proj = nn.Linear(embed_dim, embed_dim)
        self.out_proj = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):
        batch, seq, dim = x.shape

        t = self.t_proj(x).view(batch, seq, self.num_heads, self.head_dim)

        t_prev = torch.roll(t, shifts=1, dims=1)
        t_prev[:, 0, :, :] = 0

        t_next = torch.roll(t, shifts=-1, dims=1)
        t_next[:, -1, :, :] = 0

        r = t + self.phi * t_prev + self.phi_inv * t_next

        output = r.reshape(batch, seq, dim)
        return self.out_proj(output)

This implementation uses 2 * embed_dim^2 parameters compared to 4 * embed_dim^2 for standard attention. It has O(N) complexity compared to O(N^2) for standard attention. It uses only addition and scalar multiplication with no matrix multiplication for attention weights.


Appendix B: Collision Proof

Theorem: For vectors T_1, T_2, through T_n drawn from a continuous distribution, the probability that two different sequences produce the same Golden Engram is zero.

Proof sketch: The Golden Engram E equals the sum of phi times T_i and is a linear combination with irrational coefficients. For two sequences to collide, we need the sum of phi times T_i to equal the sum of phi times T'_i for different sequences T and T'. This requires phi times (T_i minus T'_i) to sum to zero for all i. Since phi is irrational and T_i are drawn from continuous distributions, this has measure zero.

Empirical validation confirmed 0 collisions in 10,000 random sequences.
